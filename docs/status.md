# Состояние проекта

Обновлено 11 ноября 2026.

## Сделано

- Каркас на Expo SDK 58 с Expo Router, маршруты в `src/app/`.
- Дизайн-система в `src/theme/tokens.ts`: цвета из переменных Figma, типографика, отступы.
- Экран «Сегодня» по варианту B из Figma (узел `4:55` в файле `cq8epRHhjqwCcDPE1tXnDl`): кольцо индекса, шкалы сфер, тезис дня, карточки.
- Таб-бар: «Сегодня», кнопка практики, «Путь». Короткое нажатие открывает практику по времени суток, долгое открывает выбор.
- Заглушка экрана «Путь».
- Экран практики с диалогом (`src/app/practice.tsx`). Ментор здоровается, подсказывает новичку, как отвечать, и задаёт два-три вопроса по сценарию практики из `src/data/dialog.ts`. Реплики ментора проявляются по словам. Под вопросом — варианты ответа чипами и «Пропустить». После последнего вопроса — прощание и кнопка «Завершить».
- Ручной ввод: поле внизу, кнопка отправки появляется, когда что-то написано.
- Голосовой ввод через `expo-speech-recognition` (`src/voice/`): плашка записи в ленте, текст появляется по мере речи, слово за словом; дуги над кнопкой «Готово» реагируют на громкость. Распознавание на русском, с пунктуацией, в непрерывном режиме. Ошибки (нет доступа к микрофону, нет сети, не расслышал) показываются над полем ввода.
- Иконки выгружены из Figma в `assets/icons/` без изменений.
- Первый коммит сделан, код лежит в репозитории `kuxwhite/ai-mentor`, ветка `main`.

## Как проверялось

Проверка типов проходит. Главная собрана в веб-версии и сверена со скриншотом из Figma; на телефоне в Expo Go открывается.

Экран практики проверен в веб-версии в браузере: приветствие, чипы, «Пропустить», ручной ввод, выбор практики долгим нажатием, завершение. Голос проверен с подменённым браузерным распознавателем, который «диктует» фразу по словам: текст появляется по мере речи, куски склеиваются в одно сообщение. Настоящее распознавание на телефоне ещё не проверялось.

## Известные расхождения и долги

- Literata чуть шире, чем в Figma: в пакете шрифта только начертание для мелкого текста. Нужен файл «Literata 24pt Regular» из официальной поставки шрифта, его надо положить в `assets/fonts/` и подключить в `src/app/_layout.tsx`.
- Свечение кольца на Android сделано через `filter: drop-shadow` и на устройстве не проверено. На iOS используется тень.
- Кольцо нарисовано через `react-native-svg`. Skia пока не подключена, она понадобится для дуг записи голоса.
- Данные статичные, лежат в `src/data/today.ts`.
- Голос не работает в Expo Go: у `expo-speech-recognition` есть нативный код, нужна сборка разработки (`npx expo run:android` или `eas build --profile development`). В Expo Go при разработке кнопка микрофона показывает демо-диктовку с пометкой, в боевой сборке без модуля — сообщение, что голос недоступен.
- На Android непрерывное распознавание поддерживается с Android 13; на 12 и ниже не проверено.
- Экрана практики нет в Figma, он собран по описанию из `docs/context.md`. Иконки отправки, отмены и «Готово» (`assets/icons/send.svg`, `close.svg`, `check.svg`) нарисованы в коде, их нужно заменить на иконки из Figma.
- Ментор идёт по заранее написанному сценарию, ответы никуда не сохраняются. Приветствие и подсказка показываются при каждом открытии практики.
- Отступ под клавиатуру сделан своим хуком `src/hooks/useKeyboardInset.ts` (стандартный `KeyboardAvoidingView` ошибается в модальном листе iOS). На телефонах не проверено.
- Свечение громкости в вебе не работает: браузер не сообщает громкость, дуги только «дышат».
- Линтер не настроен.
