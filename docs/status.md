## Известные расхождения и долги

- Literata чуть шире, чем в Figma: в пакете шрифта только начертание для мелкого текста. Нужен файл «Literata 24pt Regular» из официальной поставки шрифта, его надо положить в `assets/fonts/` и подключить в `src/app/_layout.tsx`.
- Свечение кольца на Android сделано через `filter: drop-shadow` и на устройстве не проверено. На iOS используется тень.
- Кольцо нарисовано через `react-native-svg`. Skia пока не подключена, она понадобится для дуг записи голоса.
- Данные статичные, лежат в `src/data/today.ts`.
- Линтер не настроен.
