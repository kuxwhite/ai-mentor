# AI-ментор

Мобильное приложение на Expo (React Native). Контекст продукта, аудитория и принципы описаны в `docs/context.md`. Общие правила работы с Expo лежат в `AGENTS.md`, их нужно соблюдать. Что уже сделано, известные расхождения и следующие шаги записаны в `docs/status.md`; после каждой задачи этот файл нужно обновлять.

## Как устроен код

- `src/app/` — экраны (Expo Router). `(tabs)/index.tsx` это «Сегодня», `(tabs)/path.tsx` это «Путь», `practice.tsx` это экран практики.
- `src/components/` — переиспользуемые компоненты. Текст выводится только через `AppText`.
- `src/theme/tokens.ts` — цвета, отступы, скругления и типографика. Значения совпадают с переменными в Figma. В компонентах нельзя писать цвета и размеры шрифта напрямую.
- `src/data/` — данные экранов. Сейчас это заглушки.
- `assets/icons/` — иконки в SVG, выгруженные из Figma. Они импортируются как компоненты, цвет задаётся пропом `color`.

## Правила

- Порядок работы: дизайн-система, затем экраны по одному, затем логика, затем анимации.
- Один шаг за раз: одна конкретная задача на 30–40 минут.
- Перед завершением задачи запускать `npm run typecheck`.
- Новые пакеты ставить через `npx expo install`.
- Интерфейс на русском. Голос ментора набирается шрифтом Literata, интерфейс шрифтом Onest.
