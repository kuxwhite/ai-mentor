# AI-ментор

Мобильное приложение на Expo (React Native): личный AI-ментор с короткими ежедневными практиками.

## Запуск

```bash
npm install
npx expo start
```

Дальше отсканируйте QR-код приложением Expo Go на телефоне или нажмите `w`, чтобы открыть версию в браузере.

## Что уже есть

- Дизайн-система в коде: `src/theme/tokens.ts` (цвета, отступы, типографика из Figma).
- Экран «Сегодня» по варианту B: кольцо индекса состояния, шкалы пяти сфер, тезис дня, карточки.
- Таб-бар: «Сегодня», кнопка практики, «Путь». Короткое нажатие на кнопку открывает практику по времени суток, долгое открывает выбор практики.
- Заглушки экранов «Путь» и «Практика».

Данные пока статичные, они лежат в `src/data/today.ts`.
